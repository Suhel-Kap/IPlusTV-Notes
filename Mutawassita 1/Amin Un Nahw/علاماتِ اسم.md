
## علاماتِ اسم

| نمبر | علامت                        | مثال           |
| ---- | ---------------------------- | -------------- |
| ۱    | الف و لام شروع میں ہو        | الْحَمْدُ      |
| ۲    | حرفِ جر شروع میں ہو          | بِزَيْدٍ       |
| ۳    | تنوین آخر میں ہو             | زَيْدٌ         |
| ۴    | مسند الیہ ہو                 | زَيْدُ قَائِمٌ |
| ۵    | مضاف ہو                      | غُلَامُ زَيْدٍ |
| ۶    | موصوف ہو                     | رَجُلٌ عَالِمٌ |
| ۷    | مصغر ہو                      | قُرَيْشٌ       |
| ۸    | منسوب ہو                     | بَغْدَادِيٌّ   |
| ۹    | تائے متحرک اس کے آخر میں لگے | ضَارِبَةٌ      |
| ۱۰   | مثنیٰ ہو                     | رَجُلَانِ      |
| ۱۱   | مجموع ہو                     | رِجَالٌ        |

تنبیہ: فعل تثنیہ و جمع نہیں ہوتا، باقی رہا فعل کی گردان میں تثنیہ و جمع کا صیغہ جو آتا ہے تو اس میں فاعل کی ضمیر تثنیہ و جمع ہوتی ہے، خود فعل تثنیہ و جمع نہیں ہوتا۔
